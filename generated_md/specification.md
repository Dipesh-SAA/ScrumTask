# Feature Overview
The feature involves the creation of a Scrum Interface that will interact with Jira and GitHub. The interface will receive tasks and user stories from Jira, create artifact structures for each user story, link with GitHub code, log issues or bugs, assign user stories to users, retrieve information about Epics and projects from Jira, and manage screenshots for testing purposes.

# Business Objective
The objective is to streamline the Scrum process by automating the reception of tasks and user stories from Jira, the creation of artifact structures, the linking with GitHub code, the logging of issues or bugs, the assignment of user stories to users, the retrieval of information about Epics and projects from Jira, and the management of screenshots for testing purposes.

# Functional Requirements
